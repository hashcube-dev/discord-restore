# Discord Restore

You ever get the urge to trash your Discord server but don't wanna have
to do cleanup? Introducing `dcrestore`!

> [!WARNING]
> This project is now on infinite hiatus because I hate bubbletea lists

## Development

Requirements:
- Direnv
- Nix

```sh
git clone git@github.com:hashcube-dev/discord-restore.git
cd discord-restore
direnv allow
```

### Building

```sh
nix build
```

### Running

```sh
nix run 
```
